# Gymnastics Class Timer

A full-screen friendly web timer for gymnastics sessions.

## Features

- One-click schedule modes: **Weekday**, **Saturday**, and **Sunday**
- Large visual countdown with segment-based circular progress
- Big digital time-left display for current rotation
- Timeline of all classes and segments for the selected day
- Editable coach reminders saved locally in the browser

## Run

Because this is a static app, you can run it with any local server.

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.
